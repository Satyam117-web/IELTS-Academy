# IELTS Academy Website

A modern, responsive website for IELTS preparation courses with interactive features.

## Features
- 🎯 Responsive design for all devices
- 🖼️ Image carousel with auto-slide
- 📱 Mobile-friendly navigation
- ⚡ Fast and smooth animations
- 🎨 Modern UI with gradient designs

## Tech Stack
- React.js
- Tailwind CSS
- Framer Motion (animations)
- Lucide React (icons)

## Getting Started
```bash
npm install
npm run dev
